# Prompt 05: pruebas y Docker

## Objetivo

Crear un harness ejecutable desde clon limpio.

## Prompt utilizado

> Define un harness para este proyecto con Docker Compose, migración, seed, importación, typecheck, build, auditoría de secretos, smoke tests y verificación de persistencia. Cada control debe tener comando, salida observable, código de salida y no destruir el volumen automáticamente.

## Criterio de aceptación

Otra persona debe poder levantar el sistema, importar, ejecutar controles y reiniciar sin perder datos.
